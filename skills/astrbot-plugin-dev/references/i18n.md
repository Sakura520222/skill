# 插件界面国际化

来源：[插件国际化](https://docs.astrbot.app/dev/star/guides/plugin-i18n.html)。整理日期：2026-10-23。

文件位置固定为插件目录的 `.astrbot-plugin/i18n/<WebUI locale>.json`，例如 `zh-CN.json`、`en-US.json`。文件内容必须是嵌套 JSON object，不支持点号扁平 key。

```json
{
  "metadata": {
    "display_name": "示例插件",
    "short_desc": "一句话介绍。",
    "desc": "详细功能说明。"
  },
  "config": {
    "enabled": {"description": "启用", "hint": "是否启用此功能。"},
    "mode": {"labels": ["快速", "稳妥"], "subtitles": ["较快返回", "检查更多条件"]},
    "connection": {"timeout": {"description": "超时秒数"}}
  },
  "views": {
    "settings": {"title": "设置", "description": "高级设置。", "save": "保存"}
  }
}
```

`metadata` 只覆盖展示字段，不改变插件 `name`/`author` 身份。缺少语言或字段时回退到 `metadata.yaml`、`_conf_schema.json` 或页面 fallback。

配置翻译按字段结构嵌套：`object` 下直接嵌套子字段，不增加 `items` 层；`template_list` 的模板名放 `config.<字段>.templates.<模板>.name`，模板字段继续嵌套。`labels`、`subtitles` 与原 `options` 按索引对应，只翻译展示文案。

`views.<目录名>` 对应视图标题/描述和自定义文案，旧 `pages` 为兼容别名。页面调用 `bridge.t("views.settings.save", "Save")`、`bridge.getLocale()`；`bridge.onContext(render)` 响应语言变化。修改 locale 文件后重载插件，以刷新元数据。

测试缺失翻译回退、语言切换和选项保存值保持一致。不要把这个 WebUI 国际化机制当作聊天回复自动翻译接口。
